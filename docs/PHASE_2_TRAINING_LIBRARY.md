# My Little Gym — Phase 2: Training library (revised)

Initial templates: 20 routines (5 for each body-area category), exercise library: 42 entries.

**Important:** Any number of weekly gym visits and any session length are allowed. Choose a routine when you want; the 30–55 minute estimates are not obligations. Machines at Thomaskirche are *not individually verified*. Start with manageable loads and stop any painful movement. For persistent injuries seek personalized advice.

## Legs (glute emphasis)

Calf raises stay in the searchable exercise library but are **not** part of default leg templates. Glute-drive or hip-thrust equipment is suggested because Thomaskirche advertises a Glutebuilder Booty Zone; exact machines must be checked at the club. If unavailable, use dumbbell hip thrust or a trainer-approved alternative.
